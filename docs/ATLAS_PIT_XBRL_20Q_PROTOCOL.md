# ATLAS-PIT-XBRL：20题综合正式实验协议

冻结日期：2026-08-13  
状态：运行前冻结  
模型：中转实际列出的 `claude-sonnet-5`，`medium` effort

## 1. 为什么需要新实验

旧真实实验把“最终采用证据中已明确标注且晚于截止日的比例”作为泄漏指标；日期缺失不会被计为泄漏。
独立重审发现，这个定义会让 `published_at=null` 的证据显得安全。新实验同时审计候选搜索来源、原生引用和
最终采用证据，并把“未知日期”与“确认安全”分开报告。

## 2. 开发门禁与正式测试隔离

- 开发门禁只使用旧的 `atlas_xbrl_20q_sonnet5_20260813` trace前6题，不进入新正式分数；
- 正式测试为 `pit_xbrl_20q_cases.json` 中20道新的历史截止日题；
- 新题Gold由独立 `reference_program` 在SEC Company Facts上复算，整批哈希为
  `a11e93b6974a2dd5d41c0e5de590e4dedaafc317827f2de9c34dd0f6c467172a`；
- 查看正式结果后不修改题目、Gold、日期解析规则、联合评分或阈值。

开发门禁结果：两种方法数值准确率均为6/6；普通Agent的101个候选来源中10个确认晚于截止日，
5/6题暴露未来来源，时间元数据覆盖率17.8%，联合可靠回答率0%；ATLAS的6个候选来源全部为
截止日前SEC记录，时间元数据覆盖率和联合可靠回答率均为100%。该结果只验证审计器和指标方向。

## 3. 对照系统

1. **普通Web Search Agent**：同一Claude模型，最多3次真实Web Search，两阶段生成与结构化归一；
2. **ATLAS-PIT-XBRL**：Claude只编译公司、指标、期间和公式；程序只保留 `filed <= cutoff_date` 的
   SEC 10-K事实，再用Decimal执行白名单公式。

两者使用相同模型和推理强度，但工具能力不同；这是完整Agent系统比较，不是只换Prompt的消融。

## 4. 预注册指标

- 最终决策准确率：两位小数精确相等且单位一致；
- 回答覆盖率；
- 候选未来来源数与题级暴露率；
- 候选来源时间元数据覆盖率；
- 最终采用证据的确认泄漏率与未知日期数；
- SEC来源占比和来源字段完整率；
- **联合可靠回答率**：答案正确，且最终证据全部有日期、不晚于截止日、来源字段完整。

未知日期不计为“确认未来”，但也不计为“确认安全”或联合可靠。

## 5. 成功判据

只有同时满足以下条件，项目首页才把ATLAS-PIT-XBRL表述为综合改进：

1. 准确率严格高于普通Agent；
2. 覆盖率不低于普通Agent；
3. 候选未来来源率严格更低；
4. 最终证据确认泄漏不高于普通Agent，且ATLAS为0；
5. 时间元数据覆盖率和联合可靠回答率严格更高；
6. 逐题最终准确率不出现ATLAS输给普通Agent的case。

若任何条件失败，完整结果照常公开，不更改Gold或删除有效运行。

## 6. 规模与预算

- 20题 × 2系统 = 40个case-system单元；
- 普通Agent固定2个模型HTTP阶段，ATLAS固定1个模型HTTP阶段；
- 计划60个成功模型HTTP阶段，`max_retries=0`，模型尝试上限60；
- 普通Agent每题最多3次Web Search；ATLAS使用SEC Company Facts和运行级缓存；
- 原始供应商响应仅本地保存，公开标准化trace、来源、引用、计算、哈希和排除记录。
