# 联网研究：可追溯的实际执行链路

在研究终端打开“联网研究”，输入一个新问题。浏览器向公网 FastAPI 后端提交异步任务，后台真实调用 DeepSeek 和 SEC，浏览器轮询同一任务的步骤与最终报告。网页没有模型密钥，也不会把预制案例作为联网结果。

## 六步链路

1. **规划**：DeepSeek 返回结构化研究问题、最多三条英文 SEC 检索词、申报类型和年度指标清单。公司与截止日由请求绑定；指标由程序白名单校验。未明确年份时，由本次实时数据选择最新可用年度，避免模型凭记忆猜年份。
2. **检索**：实时查询 SEC submissions 与 EDGAR Full Text Search。当前支持八家公司；EFTS 属于公开网页接口，变化或失败会显式记为缺口。无需付费搜索 Key。
3. **读取**：下载最多四篇实际申报正文，去除脚本和隐藏文本、选取相关原文段落。只允许官方 HTTPS 域名，检查 DNS、重定向、最大体积、请求次数与时间预算。搜索摘要不等于已读取证据。可选 Tavily 仅扩大到配置内的官方投资者关系网站。
4. **提取与计算**：本次重新获取 CompanyFacts，按截止日构建版本。复用已独立验证的年度数值内核，以精确有理数计算。交付前检查实体、年度、单位、数值、期间和完整操作数。季度和多年度比较未受该表支持时明示缺口，不以单一年数替代。
5. **核验**：每条模型观点必须引用实际存在的材料或已核验指标；引文必须逐字命中所读取原文；材料必须早于截止日。模型段落不承载金额、年份或比例，数值由程序表格交付。第三次 DeepSeek 调用独立检查原文上下文、引用和观点之间的支持关系，不通过的观点不展示。
6. **报告**：呈现已接纳观点、原文引文、SEC 链接、财务表、计算操作数、申报日期、实际抓取时间、SHA256、搜索记录、真实模型返回型号／请求号／token 用量及证据缺口。支持 Markdown 和 JSON 导出。

## 产品与研究的区别

这条链路借鉴已有方法文档中的“检索—核验—修订”和 Point-in-Time 门禁，并落实为真实可执行的工具步骤。它不是论文完整复现，也不是搜索覆盖面与服务保障等同于商业投研产品的承诺。

日期粒度申报从下一日开始纳入。当前抓取的历史 CompanyFacts 是重建资料，不是当时完整封存的数据库，无法消除模型参数中的未来知识。系统通过外部证据限制交付，不把模型记忆当作独立来源。

语义核验也是模型判断，仍可能遗漏错误。“接纳了六条观点”表示通过该轮门禁，不表示准确率为 100%。已有 60 道财务题和 16 道意图题测量冻结数据与解析器，不能移作本链路准确率。真实在线验收记录单独保存。

## 可检查的边界

- 每次最多三次模型请求、四篇正文、三条关键词查询；单篇材料上限 20 MB，材料抓取预算 120 秒。模型单次超时 60 秒，网页异步等待可达数分钟。
- 对来源故障不回退成离线快照；对模型起草或复核失败不交付未验证文字，保留已验证财务表和读取的材料。
- 任务采用不可枚举的高熵 ID，无公开任务列表。开启服务令牌时读取与导出也验证令牌。分享任务链接等同于分享该研究问题与结果。
- SQLite 负责单进程任务与幂等。可选 Redis 使用原子滚动窗口执行全局小时／日预算；配置 Redis 却连接失败时拒绝新付费任务。
- 免费 Render 会休眠，报告文件不保证持久保存。免费 Redis 本身重启也可能丢失预算计数；它不是服务商账户的永久消费上限。
