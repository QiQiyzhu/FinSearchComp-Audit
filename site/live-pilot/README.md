# Claude 真实 Web Search Agent：20 题 × 5 策略

这是一次真实外部有效性 pilot：实际调用 `claude-sonnet-5`，
每条运行强制 Web Search，并保存完整来源、原生 citations、提示词、token、响应 ID 和 raw hash。

## 固定实验条件

- 问题：20 道，5 策略共享同一批题；
- 有效记录：100；
- 模型：`claude-sonnet-5`；
- 推理强度：`medium`；
- 每次最多搜索：3；
- 运行窗口：2026-08-12T17:32:49.489438+00:00 至 2026-08-12T18:28:46.494181+00:00；
- 批次哈希：`555821ffd1063fbd13569c9cc01e5508c69b6cb9db058d62730190dcd5b95acc`。

## 核心结果

| 策略 | 最终决策准确率 | 模型初稿准确率 | 回答覆盖率 | 已采用证据时间泄漏 |
|---|---:|---:|---:|---:|
| 普通搜索 Agent | 55.0% | 55.0% | 75.0% | 0.0% |
| 时间约束 Prompt | 55.0% | 55.0% | 70.0% | 0.0% |
| 元数据过滤器 | 40.0% | 55.0% | 40.0% | 0.0% |
| 完整证据验证器 | 35.0% | 55.0% | 40.0% | 0.0% |
| ATLAS-RAG（校准版） | 45.0% | 45.0% | 50.0% | 0.0% |

这张表不能被解释为模型排名。最终正确率同时受到答案质量和拒答策略影响；
`case_analysis.md` 明确区分了数值错误、拒答和“正确初稿被 Gate 拒绝”。

### 按题目 bootstrap 95% CI

| 策略 | 最终正确率 | 95% CI |
|---|---:|---:|
| 普通搜索 Agent | 55.0% | 35.0%–75.0% |
| 时间约束 Prompt | 55.0% | 35.0%–75.0% |
| 元数据过滤器 | 40.0% | 20.0%–60.0% |
| 完整证据验证器 | 35.0% | 15.0%–55.0% |
| ATLAS-RAG（校准版） | 45.0% | 25.0%–65.0% |

区间由 20 道题配对重采样 10,000 次得到；它描述当前题集上的抽样不确定性，
不包含模型重复运行的随机性。

- 原生 citations：481 条；

  批准上限 200。

## 文件

- `metrics.csv`：5 策略聚合指标；
- `case_outcomes.csv`：100 个 case × strategy 结果；
- `case_analysis.md`：20 道题的中文逐题解释与失败类型；
- `confidence_intervals.csv`：按题目配对的 bootstrap 区间及相对普通 Agent 的差值；
- `trace.jsonl`：完整标准化 trace；
- `exclusions.json`：transport errors、invalid records 和排除规则；
- `study_manifest.json`：协议、哈希、运行窗口、预算与限制。

## 结论边界

本轮能说明 5 种策略在同一模型和题集上的行为差异，并揭示真实网页元数据缺失导致的
过度拒答问题。由于只有 20 题、单模型和单次运行，它仍是 pilot；下一阶段应独立解析
发布日期、重复至少三次，并报告跨运行均值/标准差与层级 bootstrap 置信区间。
